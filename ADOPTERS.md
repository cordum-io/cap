# CAP Adopters

This file lists organizations that have **publicly and with their own consent** stated
that they use the Cordum Agent Protocol (CAP) for real (non-demo) workloads.

**There are no listed adopters yet.** That is the honest current state — not a placeholder
awaiting logos. An empty list here is *not* evidence of zero adopters and an entry here is
counted toward [readiness](governance/READINESS.md) only if it independently meets the
adopter evidence rules below.

## How an adopter is added

Adoption is the **adopter's** statement, never CAP's assertion on their behalf. To be
listed, open a pull request (or point us to your public statement) providing:

1. **Organization name** and a **public URL** to *your own* statement of use (blog, docs,
   talk, README).
2. **Explicit consent** to be listed, from someone authorized to give it.
3. **Real, non-demo use** — the CAP **profile and version** you run in production or a
   comparable real setting.
4. Optional: logo/quote — each **opt-in**, used only with the consent above.

## What does not count

Per the readiness rules, the following never count as adopter evidence: the CAP reference
scheduler, Cordum itself, CAP's framework adapters or SDK wrappers, private/NDA interest,
GitHub stars or download counts, target lists, and design-partner drafts. Missing, stale,
private, or unverifiable claims are treated as **UNKNOWN**, not as an adopter.

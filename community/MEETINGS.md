# CAP Community Meetings

CAP is **async-first**. Most work happens on pull requests, RFCs, and GitHub
Discussions, so that contributors in any timezone can participate without attending a
call.

## Current status

**There is no recurring public meeting currently scheduled.** This file describes the
rules that apply **if and when** synchronous meetings are introduced. It does not imply
that meetings are happening now, and no minutes are backfilled for meetings that did not
occur.

## If meetings are introduced

- **Agenda first.** A public agenda is posted at least **7 days** before the meeting, as
  a GitHub Discussion linked from this file.
- **Open to all.** Meetings are open; joining details are in the agenda.
- **Minutes within 3 days.** Minutes are published under
  [`minutes/`](minutes/README.md) within 3 days, using
  [`MEETING_TEMPLATE.md`](MEETING_TEMPLATE.md).
- **Meetings do not decide.** A meeting can surface options and build consensus, but a
  binding outcome exists only when it is recorded in [../DECISIONS.md](../DECISIONS.md)
  with a quorum that satisfies [../GOVERNANCE.md](../GOVERNANCE.md). Minutes link to that
  decision record.
- **Confidential matters excluded.** Security embargoes and Code of Conduct details are
  **never** put in public minutes; they are handled per [../SECURITY.md](../SECURITY.md)
  and [../CODE_OF_CONDUCT.md](../CODE_OF_CONDUCT.md).

## Requesting a topic

Until a meeting cadence exists, raise topics on a GitHub Discussion or an RFC. If enough
topics accumulate to justify a call, a maintainer may schedule one under the rules above
and announce it here.

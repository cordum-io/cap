# Meeting Minutes

Published minutes of CAP community meetings live here, one file per meeting named
`YYYY-MM-DD.md`, created from [`../MEETING_TEMPLATE.md`](../MEETING_TEMPLATE.md).

**No meetings have been held, so there are no minutes.** This directory is intentionally
empty of minutes. It exists so that, when the first meeting occurs, its minutes have a
home — not to imply past meetings. Minutes are never backdated or fabricated.

See [../MEETINGS.md](../MEETINGS.md) for the meeting rules.

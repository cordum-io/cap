# Code generation & the generated-file policy

CAP's protobuf artifacts for six targets (root Go, C++, Node, root Python, SDK
Python, Ruby) are **generated**, held to an exact-bytes manifest, and must never
drift from their `.proto` sources. The full design lives in
[`tools/codegen/README.md`](../tools/codegen/README.md); this page is the policy
and the pin/update procedure.

## Policy

- Generated files are checked in and marked `linguist-generated` in
  `.gitattributes`. Do **not** hand-edit them.
- `tools/codegen/manifest.json` pins every generated output by the sha256 of its
  **LF-normalized** content, so the drift check is identical on a Windows
  (autocrlf CRLF) and a Linux CI (LF) checkout.
- `cap-codegen check` (in `.github/workflows/sdk-gates.yml`) fails on any
  changed, missing, stale, empty, or unmanifested generated file.

## Everyday check (no Docker)

```
go run ./cmd/cap-codegen check
```

## Regenerating (pinned container)

Generation runs in a digest-pinned image with the network disabled, a read-only
source mount, and a fixed `SOURCE_DATE_EPOCH`/`TZ`/`LC_ALL`:

```
tools/codegen/codegen.sh          # regenerate + verify
tools/codegen/codegen.sh --check  # build image + verify only
# Windows:
pwsh tools/codegen/codegen.ps1
```

After a deliberate regeneration, refresh and review the manifest:

```
go run ./cmd/cap-codegen snapshot
git diff tools/codegen/manifest.json    # review, then commit the generated diff separately
```

## Updating a pin

Edit the `ARG` versions in `tools/codegen/Dockerfile` (protoc, protoc-gen-go,
protoc-gen-go-grpc, grpcio-tools). CI locks the base image by immutable digest.
Bumping a pin is expected to change generated bytes — regenerate, review the
diff on its own, and re-snapshot the manifest in the same change.

## Note on the current tree

The checker is live and pins the currently checked-in tree. That tree is known
to be **drifted** (C++ is missing `handshake`+`policy`; Node, root Python, and
Ruby miss `policy`). Reconciling it via a container regeneration is a separate,
deliberately-isolated change so a large generated diff is never mixed with
hand-written logic, and is sequenced after in-flight wire-contract work.

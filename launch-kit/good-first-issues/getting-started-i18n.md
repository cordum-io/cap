# [Good First Issue] Translate getting-started guide to another language

## Area
Documentation, internationalization

## Context
The CAP getting-started guide (`docs/getting-started.md`) is currently only available in English. Translating it to other languages would make the protocol more accessible to the global developer community. Suggested languages: Chinese (zh), Spanish (es), Japanese (ja), Korean (ko), Portuguese (pt) — but any language is welcome.

## What to Do
1. Read `docs/getting-started.md` to understand the full content
2. Create a translated version at `docs/getting-started.<lang>.md` (e.g., `docs/getting-started.zh.md`)
3. Translate all prose content — keep code blocks, command examples, and file paths unchanged
4. Keep the same heading structure and section order as the original
5. Add a note at the top: "This is a community translation of [Getting Started](getting-started.md). For the latest version, refer to the English original."
6. Add a link to the translation from the original `docs/getting-started.md` (e.g., "Translations: [Chinese](getting-started.zh.md)")

## Files to Look At
- `docs/getting-started.md` — source document to translate
- `docs/` — see existing documentation style

## Definition of Done
- [ ] Translated file exists at `docs/getting-started.<lang>.md`
- [ ] All prose content translated, code blocks and paths unchanged
- [ ] Same heading structure as the original
- [ ] Note at top linking back to the English original
- [ ] Link added from the original to the translation

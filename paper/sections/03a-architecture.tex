\section{Protocol Architecture}

Figure~\ref{fig:architecture} shows the canonical control flow. Payload blobs are stored outside the bus and referenced through opaque pointers. Worker heartbeats are broadcast so schedulers can maintain a short-lived view of capacity without a persistent worker database.

\subsection{Versioned envelope}

Every bus message is a \texttt{BusPacket} containing a stable \texttt{trace\_id}, \texttt{sender\_id}, timestamp, \texttt{protocol\_version}, optional signature and runtime token, and one payload variant. Current payloads include job request, job result, heartbeat, progress, cancellation, alert, and handshake messages \citep{cap_current}. Protocol Buffers provide unknown-field tolerance and append-only schema evolution \citep{protobuf}. CAP keeps wire version 1 for additive changes and requires a version bump only for incompatible semantics.
